# Student Marks & Grade Calculator 🎓

A simple Python program that takes a student's name and marks for 5 subjects, then calculates the total marks, percentage, grade, and pass/fail result.

## Features

* Get student's name
* Enter marks for 5 subjects
* Store subjects and marks using a Python dictionary
* Calculate total marks
* Calculate percentage
* Determine student's grade
* Check whether the student passed or failed

## Grade Criteria

| Total Marks | Grade |
| ----------- | ----- |
| 400–500     | A     |
| 350–399     | B     |
| 300–349     | C     |
| 250–299     | D     |
| Below 250   | F     |

## Pass/Fail Criteria

* **50% or above** → PASSED
* **Below 50%** → FAILED

## Technologies Used

* Python
* Dictionary
* Functions
* Loops
* User Input
* Conditional Statements

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code or terminal.
4. Run:

```bash
python main.py
```
